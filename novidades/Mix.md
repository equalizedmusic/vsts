# Linha de Mix — novidades

Pacote do instalador: `InsideStudioSP-Mix` (PRISMA, TORNO, BARRAGEM, CONSOLE, SOCO, LIXA, HORIZONTE, SALA, MONITOR,
NAVALHA). A versão é o primeiro título `## x.y.z` deste arquivo: ela entra nos plugins, no instalador e no release
`mix-vx.y.z` do GitHub (com o texto da seção como nota).
Para lançar uma versão nova, escreva a seção nova AQUI EM CIMA, no mesmo commit da mudança.

## 1.0.1 — 2026-10-25
- Desinstalador: no Windows, atalho "Desinstalar" no menu Iniciar (além de Aplicativos instalados); no Mac,
  "Desinstalar InsideStudioSP Mix.command" dentro do .dmg. Os presets do usuário ficam.

## 1.0.0 — 2026-10-24
- Primeira versão numerada da linha, com tudo o que saiu até aqui:
  - PRISMA, TORNO, BARRAGEM, CONSOLE, SOCO, LIXA, HORIZONTE, SALA, MONITOR e NAVALHA;
  - presets editáveis;
  - acabamento de hardware;
  - janela que abre no tamanho salvo.
